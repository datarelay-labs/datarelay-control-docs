# Operations

Daily operation starts with Dashboard and Streams, then drills into the affected Stream, Route, or Destination.

## Runtime records

The platform records delivery logs, route outcomes, runtime snapshots/analytics, checkpoint state, schema changes, and governance/audit events.

The `/health` endpoint reports API status and a delivery-log index health probe.

## Development-branch operator features

Current development history includes:

- Data Flow Troubleshooter built from existing runtime records
- safe-change impact preview and guarded apply
- Connector/API Health derived from existing auth, credential, and delivery records
- Test Before Apply impact preview
- environment-promotion export/preview/apply

These features reuse existing runtime and configuration data instead of running a separate monitoring or deployment engine.

## Recommended drill-down

```text
Dashboard → Stream Group/Stream → Runtime evidence → Route/Destination → Action
```

Use Governance Workspace for focused governance review rather than continuous system monitoring.

# 현재 상태 & 로드맵

현재 canonical development integration branch는 `main-v2`입니다.

## 현재 Development Line에 구현된 주요 영역

- Stream/Route Runtime과 One Stream → Many Routes → Many Destinations
- Route Processing
- Local JWT/RBAC
- Credential Encryption Architecture
- Schema Observation/Drift 및 Sensitive Data Control
- Protection, Classification, Policy, Quarantine, Replay, Audit
- Dashboard 및 Runtime Evidence
- Package/Marketplace Lifecycle과 Validation
- Connector Harvester 및 AI Connector Builder Core
- Private/Remote Registry와 Signed Offline Bundle
- Data Flow Troubleshooter
- Safe Change Management
- Connector/API Health
- Test Before Apply
- Environment Promotion

## 제한적으로 설명할 영역

- External Network AI Provider 사용 가능 여부는 AI Connector Builder Core 구현과 별개입니다.
- `main-v2`에 기능이 존재한다는 사실만으로 새로운 Immutable Stable Release가 되는 것은 아닙니다.

## 현재 제품 범위가 아님

- Multi-node HA Platform
- Enterprise IAM/SSO Federation
- DataRelay Link 중앙 관리 통합
- Arbitrary Executable Marketplace Plugin
- AI Gateway / AI Proxy Product Surface

Roadmap 문구만으로 지원 기능을 주장하지 않습니다. Public Support Claim은 현재 Source, Test, Release Evidence를 따라야 합니다.

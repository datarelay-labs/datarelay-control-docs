# 용어집

**Connector** — 연결 family와 인증 capability.

**Credential** — runtime secret을 보유하는 인증 개체.

**Source** — Stream이 사용하는 구체적 source 설정.

**Stream** — runtime 실행 및 checkpoint 소유 단위.

**Route** — 목적지별 processing/delivery 단위.

**Destination** — 실제 전달 대상.

**Transform** — 사용자 관점의 Mapping + Enrichment.

**Checkpoint** — 필요한 delivery 성공 뒤 진행하는 source progress.

**Source Pack** — 선언형 integration content. runtime process가 아님.

**Marketplace** — package acquisition/lifecycle/trust layer.

**DataRelay Link** — 별도 connectivity 제품. 현재 Control 관리 통합은 구현되지 않음.

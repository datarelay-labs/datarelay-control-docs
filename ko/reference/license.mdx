# 라이선스

DataRelay Control은 **Source Available이며 Open Source가 아닙니다.**

정식 법적 조건은 [Repository LICENSE](https://github.com/datarelay-labs/datarelay-control/blob/main-v2/LICENSE)가 우선합니다. 이 페이지는 이해를 돕기 위한 요약이며 LICENSE 전문을 대체하지 않습니다.

## 허용되는 사용

현재 라이선스는 다음 사용을 허용합니다.

- 개인 사용
- 교육 및 비상업적 연구
- 평가 및 테스트
- 기업·기관 내부 상업적 사용
- 허용된 목적을 위한 내부 소스코드 수정
- 고객이 직접 통제하고 사용하는 고객 소유 환경 배포
- 고객 소유 환경에 대한 유상 설치, 통합, 마이그레이션, 유지보수, 교육 또는 지원. 단, DataRelay Control 자체를 재판매하거나 Managed Service로 제공해서는 안 됩니다.

## 별도 상용 라이선스가 필요한 사용

DataRelay Labs의 별도 서면 상용 라이선스 없이 다음 행위는 허용되지 않습니다.

- 재판매 또는 재라이선스
- 독립 상용 제품으로의 상업적 재배포
- OEM, 임베딩, 번들, White-label 제품화
- 상업적 리브랜딩 또는 포크
- DataRelay Control 기능의 SaaS, MSP, Hosted, Shared, Managed, Multi-tenant 제공
- 소스코드의 상당 부분을 사용한 경쟁·대체 상용 제품 개발·개선·유지
- Copyright, License, Attribution, Trademark 고지 제거·은폐
- OSI 승인 Open Source Software로 표현

## 고객 소유 환경

고객이 직접 배포 환경을 통제하고 사용하며 DataRelay Control 자체를 재판매하거나 Managed Service로 제공하지 않는 경우, 설치·통합·마이그레이션·유지보수·교육·지원에 대한 유상 서비스는 허용됩니다.

## 왜 Source Available인가요?

소스를 검토하고 허용된 범위에서 수정할 수 있지만 Productization, 경쟁 제품, 재판매, SaaS/MSP에 제한이 있으므로 OSI Open Source License가 아닙니다.

법적 해석은 반드시 Repository의 `LICENSE`를 기준으로 하십시오.

# DataRelay Link 관계

현재 감사한 저장소 기준으로 두 제품은 별도 제품입니다.

- **DataRelay Link**: connectivity/relay 제품
- **DataRelay Control**: 데이터 수집·처리·보호·전달·운영 제품

현재 DataRelay Control 소스에는 다음 기능이 없습니다.

- Link instance 등록
- Link heartbeat/status 동기화
- Link client/service 중앙 inventory
- Control → Link 정책 배포
- 공통 enrollment/token 프로토콜
- Link 설정 원격 push

따라서 현재 문서에서는 DataRelay Control을 DataRelay Link의 중앙 관리 서버라고 표현하지 않습니다.

# 첫 Stream 만들기

DataRelay Control은 Connector, Source, Stream, Route, Destination을 서로 다른 역할로 구분합니다.

1. **Connectors**에서 Connector를 생성하거나 개발 브랜치의 Marketplace에서 패키지를 설치합니다.
2. Credential을 별도로 구성합니다.
3. **Streams → Create First Stream**을 엽니다.
4. Connect 단계에서 기존 Connector와 Source 접근 정보를 설정합니다.
5. Sample에서 이벤트 구조를 확인합니다.
6. Destinations에서 데이터를 보낼 Destination을 하나 이상 선택합니다.
7. Route Processing에서는 목적지별로 별도 처리가 필요한 Route만 설정을 덮어씁니다.
8. Deploy 후 Dashboard/Streams에서 상태를 확인합니다.

Webhook Source가 구성된 경우 실제 ingest endpoint는 다음과 같습니다.

```text
POST /api/v1/ingest/webhook/{receiver_key}
```

`receiver_key`는 플랫폼이 만든 실제 설정값을 사용해야 합니다.

## 활용 시나리오 실습 (2026-10-18)

실제 입력 예시, 테스트 HTTP 수신기, 화면별 클릭 순서, 전송 증빙과 장애 해결까지 진행하려면 [Webhook 첫 이벤트 전송](/ko/use-cases/webhook-first-flow)을 수행하세요. 이후 [하나의 Stream에서 2개 목적지 전송](/ko/use-cases/multi-destination)으로 Route별 전송을 검증할 수 있습니다.

실제 Control 테스트 화면에 번호와 작업 캡션을 표시한 [Stream Wizard 화면 따라하기](/ko/use-cases/screen-walkthrough)를 참고하세요.

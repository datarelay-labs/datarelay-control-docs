# 첫 로그인

새 설치는 기존 계정이 없을 때 `admin` 사용자를 생성합니다.

- 기본값: `admin / admin`
- 첫 로그인 시 비밀번호 변경 필수
- `GDC_SEED_ADMIN_PASSWORD`로 초기 비밀번호 변경 가능
- bootstrap 재실행은 기존 admin 비밀번호를 초기화하지 않음

로그인하면 access/refresh JWT가 발급됩니다. 기본 access token은 60분, refresh token은 1440분 동안 유효하며 refresh할 때 새 token pair가 발급됩니다. 비밀번호를 변경하거나 모든 세션을 해제하면 `token_version`이 증가해 이전 token은 사용할 수 없게 됩니다.

Production에서는 `REQUIRE_AUTH=false`가 startup 단계에서 거부됩니다.

# 거버넌스

Governance는 별도 Compliance 제품이 아니라 선택적 **Data Control capability**입니다.

사용자는 “민감한가?”, “어떻게 보호할까?”, “전달해도 되는가?”, “위반 시 무엇을 할까?”를 정의합니다.

현재 UI에는 Governance Dashboard, Operations, Violations, Quarantine, Audit, Approvals, Replay, Notifications, Workspace 화면이 있습니다.

Stream에 공통 처리 의도를 두고 실제 적용 방식은 Route별로 다르게 설정할 수 있습니다.

Governance Workspace는 일부 기능이 아직 읽기 전용입니다. Route가 많아지면 화면을 채우기 위한 API 요청 수도 늘어날 수 있습니다.

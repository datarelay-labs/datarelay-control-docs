# 인증 & 권한

`POST /api/v1/auth/login`은 로컬 사용자를 확인하고 access/refresh JWT를 반환합니다. 잘못된 로그인은 username 존재 여부를 노출하지 않도록 동일한 `USER_AUTH_FAILED`를 반환합니다.

Password는 bcrypt로 hash됩니다.

Token 기본값:
- Access: 60분
- Refresh: 1440분
- Refresh 시 token pair rotation
- password 변경 또는 all-session revoke 시 `token_version` 증가

Viewer는 기본적으로 읽기 전용이며 일부 preview 요청만 허용됩니다. 사용자 관리, signing key 관리, 환경 간 설정 승격 적용 같은 고위험 작업은 Administrator가 필요합니다.

`REQUIRE_AUTH=false` 개발 모드는 운영 환경에서 시작할 때 거부됩니다.

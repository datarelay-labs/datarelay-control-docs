# DataRelay Control

DataRelay Control은 현재 [`datarelay-labs/datarelay-control`](https://github.com/datarelay-labs/datarelay-control)에 구현된 소프트웨어의 공개 제품명입니다. 현재 코드는 단순 관리 서버가 아니라 **Enterprise Data Control Gateway**로 동작합니다. 데이터를 수집하고, 필요한 처리를 적용한 뒤, 하나 이상의 목적지로 전달합니다.

## 핵심 모델

```text
One Stream → Many Routes → Many Destinations
```

Stream은 실행과 체크포인트를 소유하고, Route는 목적지별 Transform·Protection·Classification·Policy·Delivery를 담당합니다.

## 현재 관리 가능한 영역

- 사용자, 역할, 로그인 세션
- Connector, Credential, Source, Stream, Route, Destination
- Mapping/Enrichment 기반 Transform
- 선택적 Protection, Classification, Policy, Quarantine, Replay
- Dashboard, runtime evidence, audit, backup
- 개발 브랜치의 Marketplace, Safe Change, Troubleshooter, Environment Promotion

## 현재 지원하지 않는 제품 정체성

DataRelay Control은 VPN, 일반 RMM, SASE, SIEM, SOAR, Data Lake, Enterprise IAM 제품이 아닙니다.

또한 현재 소스에는 **DataRelay Link 등록·heartbeat·정책 배포·상태 동기화 프로토콜이 없습니다.** 따라서 DataRelay Link의 중앙 관리 서버라고 설명하지 않습니다. 자세한 내용은 [DataRelay Link 관계](/ko/getting-started/data-relay-link)를 참고하십시오.

라이선스 조건과 허용/금지 예시는 [라이선스](/ko/reference/license)에서 확인할 수 있습니다.

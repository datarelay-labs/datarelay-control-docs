# DataRelay Control

DataRelay Control은 [`datarelay-labs/datarelay-control`](https://github.com/datarelay-labs/datarelay-control)에 구현된 Source Available **기업용 데이터 제어 게이트웨이**입니다.

단순한 관리 서버가 아니라 실제 데이터 흐름에 참여합니다. 데이터를 수집하고 필요한 변환과 Route별 보호·정책을 적용한 뒤, 전달 기록을 남기면서 하나 이상의 Destination으로 보냅니다.

## 핵심 모델

Stream은 실행과 Source 진행 상태를 관리하고, Route는 Destination별 변환·보호·분류·정책·전달을 담당합니다.

## 현재 제품 Surface

- Connector, Credential, Source, Stream, Route, Destination
- Mapping/Enrichment 기반 변환
- Route별 보호, 분류, 정책, 격리, 재처리
- Dashboard, Stream 실행 상태, 전달 기록, Checkpoint, Audit
- Local User, Role, JWT Session, RBAC
- Backup, Restore, Upgrade, Health, Troubleshooting
- 현재 개발 브랜치의 Marketplace/패키지 관리, Safe Change, Connector/API 상태 확인, 적용 전 테스트, 환경 간 설정 승격

## 제품 경계

DataRelay Control은 VPN, 일반 RMM, SASE, SIEM, SOAR, Data Lake, 기업 IAM, 티켓 시스템, AI Agent 플랫폼을 대체하는 제품이 아닙니다.

또한 **DataRelay Link의 중앙 관리 제품이 아닙니다.** 현재 Control 소스에는 Link 등록, Heartbeat, 정책 전달, 상태 동기화, 공통 관리 프로토콜이 구현되어 있지 않습니다. [DataRelay Link 관계](/ko/getting-started/data-relay-link)를 참고하십시오.

## 라이선스

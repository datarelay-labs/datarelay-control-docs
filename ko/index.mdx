# DataRelay Control

DataRelay Control은 [`datarelay-labs/datarelay-control`](https://github.com/datarelay-labs/datarelay-control)에 구현된 Source Available **Enterprise Data Control Gateway**입니다.

단순 관리 서버가 아니라 실제 Data Path에 위치합니다. 데이터를 수집하고, 필요한 Transform과 Route별 Protection/Policy를 적용하고, 운영 Evidence를 남긴 뒤 하나 이상의 Destination으로 전달합니다.

> **One Stream → Many Routes → Many Destinations**

<Note>
현재 제품 Repository README와 CHANGELOG는 release line을 **GA v1.0.2**로 표시합니다. Immutable Git Tag 증거는 [릴리스 상태](/ko/reference/release-status)에서 별도로 구분합니다. 현재 개발 문서는 canonical `main-v2` source를 따르며 development-only behavior와 release-proven behavior를 구분합니다.
</Note>

## 핵심 모델

Stream은 실행과 Source Progress를 소유하고, Route는 Destination별 Transform·Protection·Classification·Policy·Delivery를 담당합니다.

## 현재 제품 Surface

- Connector, Credential, Source, Stream, Route, Destination
- Mapping/Enrichment 기반 Transform
- Route별 Protection, Classification, Policy, Quarantine, Replay
- Dashboard, Streams Runtime View, Delivery Evidence, Checkpoint, Audit
- Local User, Role, JWT Session, RBAC
- Backup, Restore, Upgrade, Health, Troubleshooting
- 현재 development line의 Marketplace/Package Lifecycle, Safe Change, Connector/API Health, Test Before Apply, Environment Promotion

## 제품 경계

DataRelay Control은 VPN, 일반 RMM, SASE, SIEM, SOAR, Data Lake, Enterprise IAM, Ticketing, AI Agent Platform이 아닙니다.

또한 **DataRelay Link의 중앙 관리 제품이 아닙니다.** 현재 Control source에는 Link Registration, Heartbeat, Policy Delivery, State Synchronization, 공통 Management Protocol이 구현되어 있지 않습니다. [DataRelay Link 관계](/ko/getting-started/data-relay-link)를 참고하십시오.

## 라이선스

DataRelay Control은 **Source Available이며 Open Source가 아닙니다.** 법적 조건은 Repository의 `LICENSE`가 우선합니다. 현재 허용 범위에는 개인 사용, 연구/평가, 기업 내부 상업적 사용, 허용된 내부 수정, 고객 소유 환경 배포가 포함됩니다. Productization, 재판매/OEM, White-label, 경쟁 제품, SaaS/MSP/Hosted 제공에는 별도 서면 상용 라이선스가 필요합니다.

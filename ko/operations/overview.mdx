# 운영 개요

일상 운영에서는 먼저 Dashboard와 Streams에서 상태를 확인하고, 문제가 있는 Stream → Route → Destination 순서로 세부 내용을 확인합니다.

실행 중에는 전달 로그, Route 결과, snapshot/analytics, Checkpoint, 스키마 변경, governance/audit 기록이 남습니다.

개발 브랜치에는 Data Flow Troubleshooter, Safe Change, Connector/API Health, Test Before Apply, Environment Promotion 기능이 구현되어 있습니다. 모두 기존 실행 기록과 설정 정보를 바탕으로 동작합니다.

# 문제 해결

기본 확인:

```bash
docker compose -f deploy/docker-compose.https.yml ps
curl -k https://localhost:18443/health
```

로그인 문제라면 운영 환경에서 `REQUIRE_AUTH=true`, `AUTH_DEV_HEADER_TRUST=false`, 충분히 강한 secret 설정을 확인합니다.

데이터가 들어오지 않으면 Connector/Credential → Source → 추출/Sample → Stream 상태 → Checkpoint 순서로 봅니다.

데이터가 나가지 않으면 Destination → Route 활성화 → Route Processing 결과 → 재시도/실패 정책 → 전달 로그 순서로 확인합니다.

Webhook endpoint:

```text
POST /api/v1/ingest/webhook/{receiver_key}
```

같은 Stream 실행이 이미 진행 중이면 409 `RUN_ALREADY_ACTIVE`가 발생할 수 있습니다.

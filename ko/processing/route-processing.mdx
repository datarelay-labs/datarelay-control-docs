# Route Processing

```text
One Stream → Many Routes → Many Destinations
```

Route마다 다음 순서를 가집니다.

```text
Transform → Protection → Classification → Policy → Delivery
```

공통 설정을 상속하고 특정 목적지만 다른 동작이 필요할 때 Override하는 방식이 기본입니다.

Classification/Protection override 설정이 불완전하면 Deploy 후에도 **Intent only**로 남을 수 있습니다. 이 경우 Route 편집 화면에서 필요한 설정을 모두 저장한 뒤 Effective Status가 `Overridden`인지 확인하십시오.

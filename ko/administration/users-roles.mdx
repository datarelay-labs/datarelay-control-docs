# 사용자 & 역할

DataRelay Control은 로컬 사용자와 JWT session을 사용합니다.

- **Administrator**: 사용자 관리, trusted signing key 관리, 환경 간 설정 승격 적용 등 고위험 작업
- **Operator**: 일반 workspace 및 package lifecycle 작업
- **Viewer**: 기본적으로 read-only, 일부 비변경 preview POST만 허용

현재 제품은 SAML, OIDC federation, SCIM, 외부 IdP 기반 사용자 프로비저닝을 지원 범위에 포함하지 않습니다.

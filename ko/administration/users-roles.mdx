# 사용자 & 역할

DataRelay Control은 로컬 사용자와 JWT session을 사용합니다.

- **Administrator**: 사용자 관리, trusted signing key, environment promotion apply 등 고위험 관리 작업
- **Operator**: 일반 workspace 및 package lifecycle 작업
- **Viewer**: 기본적으로 read-only, 일부 비변경 preview POST만 허용

현재 제품 범위에는 SAML, OIDC federation, SCIM, 외부 IdP 기반 user provisioning이 포함되지 않습니다.

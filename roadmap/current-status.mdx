# Current Status & Roadmap

This page distinguishes implemented behavior from product plans.

## Current development line

The canonical development integration branch is `main-v2`.

Implemented areas include:

- core Stream/Route runtime and One Stream → Many Routes → Many Destinations
- Route Processing
- local JWT authentication and RBAC
- encrypted credential architecture
- schema observation/drift and sensitive-data controls
- Protection, Classification, Policy, Quarantine, Replay, and audit
- Dashboard and runtime evidence
- package/Marketplace lifecycle and validation
- Connector Harvester and AI Connector Builder core
- private/remote registry administration and signed offline bundle paths
- Data Flow Troubleshooter
- Safe Change Management
- Connector/API Health
- Test Before Apply
- Environment Promotion

## Bounded / do not overclaim

- External-network AI provider availability is separate from the implemented AI Connector Builder core.
- Feature presence on `main-v2` does not by itself create a new immutable stable release.

## Not current product scope

- multi-node HA platform
- enterprise IAM/SSO federation
- DataRelay Link centralized management/integration
- arbitrary executable Marketplace plugins
- AI Gateway / AI Proxy product surface

Roadmap text is not implementation evidence. Public support claims should follow current source, tests, and release evidence.

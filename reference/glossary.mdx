# Glossary

**Connector** — Connection family and authentication capability boundary.

**Credential** — Secret-bearing runtime authentication object.

**Source** — Concrete source configuration consumed by a Stream.

**Stream** — Runtime execution unit and source/checkpoint owner.

**Route** — Destination-specific processing and delivery unit.

**Destination** — Concrete event delivery target.

**Transform** — User-facing concept covering Mapping and Enrichment; they remain separate internal stages.

**Protection** — Optional data-protection actions before delivery.

**Classification** — Optional event classification used by control policy.

**Policy** — Rules that influence delivery/control outcomes.

**Checkpoint** — Source progress state advanced only after the required delivery outcome.

**Source Pack** — Declarative integration package content; not a runtime process.

**Marketplace** — Package acquisition/lifecycle/trust layer around the Connector Registry.

**DataRelay Link** — Separate connectivity/relay product; no Control management integration is implemented in the audited source.
